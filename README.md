# Selenium Automation Project 🚀

This is a sample Selenium automation project built using Java and TestNG.  
It covers basic to intermediate level automation scenarios for web applications.

## 🔧 Tech Stack Used

- 🧠 **Language**: Java
- 🕸️ **Automation Tool**: Selenium WebDriver
- ✅ **Test Framework**: TestNG
- 🔍 **Browser**: Chrome (can be extended to Firefox, Edge)
- ⚙️ **Build Tool**: Maven
